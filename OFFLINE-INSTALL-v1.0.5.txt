Loading Business Ledger v1.0.5 — Offline fix
=========================================

Fixes the persistent "Preparing offline access..." message.
Verifies both the active service worker and its cached HTML before claiming readiness.
Adds a helpful retry prompt instead of waiting forever. Uses cache-first offline
navigation and does not change the local ledger data structure.

Upload ALL of these items to the SAME directory in GitHub Pages:
  index.html, sw.js, manifest.webmanifest, offline-icon-192.png,
  offline-icon-512.png
Keep existing app logos and icons in that same directory.

IMPORTANT
- Always back up via JSON Backup before replacing files or resetting the website.
- For v1.0.5 both index.html AND sw.js MUST be replaced together.
- iPhone: open the installed Home Screen application ONLINE once and allow offline setup.
  Safari and a Home Screen installation can have different website storage.
- After "Offline ready" appears, turn on Airplane Mode, close the application,
  and relaunch to verify offline startup.
- First ever launch on a never-installed device without internet is impossible
  for a remotely hosted GitHub Pages site.
- If setup fails, the status now identifies a failure and can be tapped to retry.
- Do not clear Safari website data or delete the Home Screen app before exporting
  your ledger data; this may delete locally stored business records.
